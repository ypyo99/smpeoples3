# 에스엠피플스 홈페이지 시안

보안 솔루션 회사 홈페이지 디자인 시안입니다. 시안 편집기(Claude 디자인 캔버스)에서 만든 화면을 브라우저로 바로 열어 볼 수 있게 정리했습니다.

## 여는 방법

`index.html`을 더블클릭하세요. Chrome이나 Edge에서 메인 화면이 열립니다.

| 파일 | 화면 |
| --- | --- |
| `Main.dc.html` | 1. 메인 홈페이지 |
| `Solutions.dc.html` | 2. 솔루션 찾기·비교 |
| `Support.dc.html` | 3. 기술지원·회사 소개 |

화면 사이의 메뉴 링크, 솔루션 필터와 비교, 문의 메일 작성은 그대로 동작합니다.

## 폴더 구성

- `images/`: 회사 로고(밝은 배경용, 어두운 배경용)와 벤더 로고 15개
- `support.js`, `vendor/`: 화면을 그리는 데 필요한 스크립트입니다. 지우면 화면이 열리지 않습니다.
- 글꼴(IBM Plex Sans KR, IBM Plex Mono)은 Google Fonts에서 불러옵니다. 인터넷에 연결되어 있지 않으면 기본 글꼴로 보입니다.
